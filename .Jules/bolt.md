## 2026-05-18 - Laravel Cache::rememberForever and Null Values
**Learning:** In Laravel, `Cache::rememberForever` treats `null` as a cache miss. This means if a database query inside the closure returns `null` (e.g., when a setting does not exist in the DB), it will not be cached, and the query will run on every request. While it optimizes the happy path, it doesn't prevent DB queries for missing records. Also, always evaluate fallback defaults outside the cache closure to avoid globally caching context-specific defaults.
**Action:** When caching database lookups that frequently return `null`, consider caching a special marker string (like 'NULL_VALUE') instead, or accept that missing values will still hit the database. Always evaluate fallbacks outside the cache closure.
