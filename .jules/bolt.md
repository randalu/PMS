## 2024-06-07 - [Prevent N+1 query when rendering category name in product card]
**Learning:** [When fetching a collection of models through a relationship (e.g., $category->products()), if the child models (products) need to access their parent (category) in the view, it causes an N+1 query issue because each child tries to load the parent again, even though it was the parent that just loaded the children. Eager loading with 'with' (e.g., $category->products()->with('category')) is an anti-pattern here because it executes a redundant database query to fetch the exact same parent model that is already in memory.]
**Action:** [Use Laravel's higher-order collection proxy `each->setRelation(...)` to manually inject the already-loaded parent model instance into each child's relationship. E.g., `$products->each->setRelation('category', $category);`. This prevents the redundant query and is extremely efficient.]
