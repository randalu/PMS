## 2024-05-14 - Global Settings Caching Optimization
**Learning:** Found a performance bottleneck where global settings were retrieved from the database on every call to `Setting::getValue()`. Since application settings are read frequently but updated rarely, this causes redundant database queries. Caching the database query result with a fallback ensures a faster read operation, but requires careful handling of cache invalidation in Model events to avoid stale data.
**Action:** Always implement caching for frequently accessed, rarely updated configurations or settings. Use the `Cache::rememberForever` function, evaluate fallback values outside of the closure to avoid caching defaults when missing, and implement proper cache clearing in Eloquent `saved` and `deleted` hooks, ensuring to forget the `original` key if it was modified.
